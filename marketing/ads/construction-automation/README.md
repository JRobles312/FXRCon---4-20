# ThaDotCompany — Construction Automation Social Ads

Social media ad set for **Thadotcompany.com** promoting automation services to
construction companies. Visual direction matches the ThaDotCompany "connect-the-dots"
brand aesthetic: deep charcoal canvas, glowing orange node network, Acumin Pro type.

## Format
- **Aspect ratio:** Story / vertical — 1080 × 1920 px
- **Languages:** English + Spanish (two pages)

## Files
| File | Description |
| --- | --- |
| `thadot_construction_ads.html` | Source design (self-contained HTML, both languages as `.story` roots) |
| `thadot-construction-ad-en.png` | English ad — flat preview/export |
| `thadot-construction-ad-es.png` | Spanish ad — flat preview/export |

## Editable version
The design was also exported to an editable Adobe Express document
(2 pages: English, Spanish) tied to the connected Adobe account.
